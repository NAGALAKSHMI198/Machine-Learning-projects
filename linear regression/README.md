# 🏠 House Price Prediction using Linear Regression

## 📌 Overview

This project demonstrates the implementation of a **Linear Regression** model using Scikit-learn to predict house prices based on selected housing features. It covers the complete machine learning workflow, including data loading, preprocessing, model training, prediction, evaluation, and visualization.

The project uses the **Boston Housing Dataset** for educational purposes to understand the fundamentals of regression analysis.

---

## 🎯 Objectives

- Understand the Linear Regression algorithm.
- Load and preprocess the dataset.
- Train a Linear Regression model.
- Predict house prices based on input features.
- Visualize the relationship between features and the target variable.
- Evaluate the trained model.

---

## 📂 Dataset

**Dataset:** Boston Housing Dataset

### Features Used
- **CRIM** – Per capita crime rate by town
- **ZN** – Proportion of residential land zoned for large lots
- **AGE** – Proportion of owner-occupied units built before 1940

### Target Variable
- **PRICE** – Median value of owner-occupied homes
