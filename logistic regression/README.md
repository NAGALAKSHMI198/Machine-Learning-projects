# 🌸 Iris Flower Classification using Logistic Regression

## 📌 Overview

This project implements a **Logistic Regression** model using Scikit-learn to classify Iris flowers into three different species based on their physical characteristics. The project demonstrates the complete machine learning workflow, including data loading, preprocessing, model training, prediction, evaluation, and visualization using a confusion matrix.

The model is trained on the famous **Iris Dataset**, one of the most widely used datasets for learning classification algorithms.

---

## 🎯 Objectives

- Understand the Logistic Regression algorithm.
- Load and explore the Iris dataset.
- Split the dataset into training and testing sets.
- Train a Logistic Regression classifier.
- Predict flower species.
- Evaluate model performance using accuracy and confusion matrix.
- Visualize classification results.

---

## 📂 Dataset

**Dataset:** Iris Dataset (Scikit-learn)

### Input Features

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

### Target Classes

- Setosa
- Versicolor
- Virginica
