# 🤖 Machine Learning Projects

A collection of beginner to intermediate Machine Learning projects implemented using Python and Scikit-learn. This repository demonstrates the implementation of various machine learning algorithms, including data preprocessing, model training, evaluation, visualization, and prediction.

## 📌 About

This repository contains hands-on machine learning projects built to strengthen my understanding of supervised and unsupervised learning algorithms. Each project is implemented using Jupyter Notebook and follows a structured machine learning workflow.

## 🚀 Projects Included

- 📈 Linear Regression – House Price Prediction
- 📊 Logistic Regression
- 🌳 Decision Tree
- 🌲 Random Forest
- 👥 K-Nearest Neighbors (KNN)
- 📉 Support Vector Machine (SVM)
- 📧 Naive Bayes
- 🎯 K-Means Clustering
- 🧠 More projects will be added regularly.
